# Asale 销售辅助系统

面向一线销售人员的桌面端 AI 客户沟通工作台交互原型。

## 当前原型

- 消息总览与待回复客户列表
- 客户会话快速切换
- 实时 AI 意图与价值判断
- 推荐话术插入、替换和追加
- 客户草稿自动保存
- 客户画像摘要与完整资料抽屉
- 客户对话与 AI 区域比例调节
- 结束处理、沟通总结与客户数据确认

当前版本使用脱敏演示数据，尚未连接真实企业微信接口。

## 在线预览

[https://asale-henna.vercel.app](https://asale-henna.vercel.app)

## 本地运行

需要 Node.js `22.x`。

```bash
npm install
npm run dev
```

打开终端输出的本地网址即可查看原型。

## 检查

```bash
npm test
```
